# گل‌پول | Golpool Finance

پیش‌نمونه مستقل حسابداری شخصی فارسی با تمرکز بر تجربه کاربری ساده و هویت بصری زنانه.

## وضعیت واقعی
- UI پنج‌صفحه‌ای Flutter و سیستم طراحی پاستلی: کدنویسی اولیه
- ثبت دستی هزینه و ذخیره رمزگذاری‌شده **تراکنش‌ها** از طریق Secure Storage: پیاده‌سازی اولیه؛ آزمون دستگاه لازم
- آزمون‌های محاسباتی، قوانین زمان یادآوری و تحلیل پیامک: سورس آزمون موجود، نتایج CI باید بررسی شوند
- قفل بیومتریک: سرویس آماده ولی هنوز به مسیر ورود برنامه متصل نشده
- یادآوری ۲۱ و ۲۲:۳۰: **فقط قوانین زمان‌بندی**؛ اعلان سیستم هنوز اجرا نشده
- دریافت پیامک بانکی در iOS: خودکار نیست، صرفاً تحلیلگر متن اختیاری موجود است
- سایر داده‌ها (هدف‌ها، بودجه، قرض‌ها و حساب‌ها) در این نسخه همچنان داده‌های نمونه/حافظه‌اند و هنوز به ذخیره دائمی متصل نشده‌اند
- فایل APK: صرفاً پس از موفقیت CI قابل تأیید

**با اطلاعات مالی واقعی استفاده نکنید.**

## CI
Workflow: `.github/workflows/flutter-check.yml` 
```bash
flutter create --platforms=android,ios --project-name golpool .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

در GitHub Actions بخش Artifacts را فقط پس از سبزشدن کارها بررسی کنید.
پکیج‌ها در pubspec تعریف شده‌اند و نصب واقعی آن‌ها به اجرای flutter pub get در CI وابسته است.

## امنیت
اطلاعات تراکنش در FlutterSecureStorage ذخیره می‌شود، نه SharedPreferences.
هنوز به ممیزی امنیتی، بازیابی داده و آزمون خطاهای دستگاه نیاز دارد. کلید یا رمز بانکی وارد مخزن نکنید.
